- [x] Owner schema/seed setup and read-only 25-product confirmation.
- [x] Transactional ordering/RLS/staff membership and local concurrency regression tests.
- [x] Responsive desktop/tablet/mobile browser fixtures.
- [ ] Dedicated-project real registration/email and staff grant.
- [ ] Live ORS function deployment, secrets, authorized origins and route verification.
- [ ] Explicit hosted test order permission and real persistence check.
- [ ] Real Android installation/keyboard/location/back/session/network check.
- [ ] Security/performance dashboard advisors and SMTP/hosting redirect review.
- [ ] User approval for web publication; production Android signing/store release is separate.
